ReturnWise System Architecture

  • Backend: Python 3.14 with Flask REST API
  • Database: SQLite with foreign keys and index optimization (Zero config required)
  • Decision Engine: Modular rule-based expert system (`recovery_engine.py`) calculating Net Recovery ($Net = Resale - Processing$)
  • Root-Cause Analytics: Statistical cross-tabulation engine (`root_cause_engine.py`) comparing customer complaint vs technician verification with sample-size safeguards ($N \ge 3$)
  • Frontend: Native Semantic HTML5, Modular JavaScript (ES6+), Modern SaaS CSS, Chart.js
